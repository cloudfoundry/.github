# Cloud Foundry Community Overview

The Cloud Foundry community operates on a well-defined, transparent role system that recognizes contributions and grants responsibilities based on sustained engagement. The community follows a progression model outlined in the official [ROLES.md](https://github.com/cloudfoundry/community/blob/main/toc/ROLES.md) document:

## 🌱 Contributor → 🔧 Reviewer → 🛠️ Approver

**Want to see how it actually works?** Check out [some promotion PRs](https://github.com/cloudfoundry/community/pulls?q=is%3Apr+is%3Aclose+promotion+).

### What the PRs Shows You:

✅ **Clear nomination process** - The requirements for each role are defined in [ROLES.md](https://github.com/cloudfoundry/community/blob/main/toc/ROLES.md)
✅ **Evidence of contributions** - There is a supported tool ([contributions-for-user.sh](https://github.com/cloudfoundry/community/blob/main/toc/working-groups/contributions-for-user.sh)) to generate your contribution history. Just execute the tool like `./contributions-for-user.sh "<gh-user>" "<WG-name>"`
✅ **Transparent evaluation** - Public discussion and approval by defined criteria in [ROLES.md](https://github.com/cloudfoundry/community/blob/main/toc/ROLES.md)

This is how Cloud Foundry recognizes merit: publicly, transparently, and based on demonstrated interest.

## Your Journey Starts Now

The Cloud Foundry community is open, welcoming, and merit-based. Whether you're fixing a typo in documentation or architecting the next major feature, your contributions matter.

Don't wait for permission. Don't wait until you're "ready."
